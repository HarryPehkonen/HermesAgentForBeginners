# Chapters

One file per chapter: `NN-slug.md` (e.g. `03-memory.md`), numbered to match
`../plan.md`. No content yet — the plan is the contract, the chapters follow the
template it defines: what you will be able to do · the idea · do this · verify it
· what broke for me · pitfalls · where to go next.

Rules that apply to every chapter:

- Commands were run on a real install; output is real or explicitly marked as
  trimmed.
- The chapter states the Hermes version it was verified against.
- Numbers are measured, not estimated.
