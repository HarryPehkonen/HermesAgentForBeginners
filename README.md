# Hermes Agent for Beginners

A book for people who have used a chat model, have a terminal open, and want an
agent that actually remembers things.

It is written as a learning log: what each part of Hermes is for, what it costs,
and the mistakes made on the way. The interesting material is not the feature
list — it is how memory caps, the skill index, profiles, background work and the
curator quietly interact.

**Status: plan only.** There is no chapter content yet. The plan — what the book
covers, in what order, and how each chapter gets written — is in
[`plan.md`](plan.md).

## What the book covers

- **Memory** — the character-capped files that shape every reply, and the
  pointer discipline that keeps them small.
- **Holographic memory** — facts you query instead of facts you paste.
- **Skills** — procedures that load on demand, and the per-turn cost of the
  skill list itself.
- **Profiles** — several agents in one install, which is also the structural
  answer to "my memory and skills got too big".
- **Kanban** — handing durable work to another profile.
- **Background work** — scheduled jobs, background processes, subagents, and
  which results actually reach the agent.
- **The curator** — maintenance for a library that grows itself.
- **Extending and maintaining Hermes** — the extension surfaces in cost order,
  and the monthly health checklist.

## How to read it

Chapters are numbered and each one assumes only the chapters before it. Every
command was run on a real install, every number was measured, and each chapter
records the Hermes version it was verified against.
